# Adekunle-Mercy-Portfolio

A premium, professional video production and editing portfolio for **Mercy Olufunke Adekunle**.

## Overview
- **Creative Focus**: Commercial video editing, viral short-form social campaigns (Reels, TikTok, Shorts), precision color grading, and broadcast-standard audio engineering.
- **Experience**: 5+ years of post-production leadership, 200+ projects delivered, 5M+ organic video views.
- **Tools**: DaVinci Resolve, Adobe Premiere Pro, After Effects, CapCut Pro.

## Features
- Pure white minimal aesthetic (#FFFFFF)
- Responsive multi-device optimization (320px to 4K displays)
- Interactive featured video slider with native touch swipe and mouse drag
- Interactive before & after color grading comparison slider (LOG vs. Rec.709)
- Framer-grade smooth spring scroll reveal animations
- Direct WhatsApp and Email integration

## Local Development
Start the local streaming server:
```bash
node server.js
```
Open [http://localhost:3000/](http://localhost:3000/) in your browser.

## Deployment
Configured with `vercel.json` for deployment on [Vercel](https://vercel.com).
